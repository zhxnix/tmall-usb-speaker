# A15 · 骷髅小兵

Source: [KayKit Character Pack: Skeletons](https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0), `Characters/gltf/Skeleton_Minion.glb`.

License: CC0 1.0; the pack license is kept in `LICENSE.txt`. This is a local customer candidate and does not replace the original skeleton mage. `main.glb` keeps the minion's cloak, skull, jaw and eyes, source skin weights and animations. The source contains no retained hand weapon.

The source rig has the same 41-bone KayKit humanoid layout as A15 骷髅法师: `upperarm.l/r`, `lowerarm.l/r`, `wrist.l/r`, `hand.l/r` and `handslot.l/r`. `Idle` and `Walking_C` are retained, together with the pack's other animation clips. Recommended fitting is shoulder height 1.10 m and head scale 0.52.
