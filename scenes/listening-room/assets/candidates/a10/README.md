# A10 · Hooded Rogue candidate

Source: [KayKit Character Pack: Adventures](https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0), `Characters/gltf/Rogue_Hooded.glb`.

License: CC0 1.0; the repository license is kept beside this file. The model is a temporary candidate for the customer test scene and is not yet part of the production customer roster.

The prepared `main.glb` keeps the hood, cape, clothing, skin weights and the original 41-bone `Rig`. Hand weapons and throwables are removed for a neutral record-shop customer. It retains the original animation clips, including `Idle`, `Walking_A/B/C`, `Interact`, `PickUp`, `Cheer`, `Lie_*`, `Sit_*`, `Jump_*`, `Dodge_*`, `Unarmed_*` and combat clips for later retarget decisions.

Hand-related joints in the source rig include `upperarm.l/r`, `lowerarm.l/r`, `wrist.l/r`, `hand.l/r`, `handslot.l/r`, plus IK controls. The source is authored as a normal KayKit humanoid glTF/GLB character and keeps its source bind pose. No scene code or device files were changed for this candidate.
