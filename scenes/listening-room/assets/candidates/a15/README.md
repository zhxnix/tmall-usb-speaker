# A15 · Skeleton Mage candidate

Source: [KayKit Character Pack: Skeletons](https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Skeletons-1.0), `Characters/gltf/Skeleton_Mage.glb`.

License: CC0 1.0; the repository license is kept beside this file. The model is a temporary candidate for the customer test scene and is not yet part of the production customer roster.

`main.glb` keeps the mage hat, robe/body, jaw and eyes, with the original 41-bone `Rig`. It has 95 original clips, including `Idle`, `Idle_B`, `Idle_Combat`, `Walking_A/B/C/D_Skeletons`, `Interact`, `PickUp`, `Spellcast_*`, `Skeletons_Awaken_*`, `Lie_*`, `Sit_*`, `Jump_*`, `Cheer` and `Taunt`. No hand weapon object is part of this candidate file.

Hand-related joints in the source rig include `upperarm.l/r`, `lowerarm.l/r`, `wrist.l/r`, `hand.l/r`, `handslot.l/r`, plus IK controls. The source is authored as a normal KayKit humanoid glTF/GLB character and keeps its source bind pose. No scene code or device files were changed for this candidate.
