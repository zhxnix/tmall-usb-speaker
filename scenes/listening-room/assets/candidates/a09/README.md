# A09 · Quaternius Wizard

Original pack and licence evidence: https://quaternius.com/packs/rpgcharacters.html (CC0).
Author's public download folder: https://drive.google.com/drive/folders/1MIRQXLfTd21HMI5rwOb6Xy0rv0xv1m8b
The listed glTF file is `Wizard.gltf` (Drive file `1OfEos4LtQLrMfJLpw2OdBNhbu36RtZUd`). The author's download endpoint returned a quota-exceeded page when fetched.

The source used here was downloaded from https://raw.githubusercontent.com/euuuuuuan/cairnfall-public/main/assets/vendor/quaternius_rpg/Wizard.gltf . That public project's https://github.com/euuuuuuan/cairnfall-public/blob/main/CREDITS.md records this folder as the same Quaternius RPG Character Pack, CC0, and links the original author page.

`source/Wizard.gltf` is the downloaded self-contained source. `main.glb` preserves its buffers, textures, original skin weights and all 15 animation tracks, packaged directly without skeleton re-export. Only the `Wizard_Staff` mesh attachment is detached; face, beard, clothes, shoulder pads and belt pouch are retained. A source tool is at `tools/prepare_quaternius_candidates.py`. See `model-info.json` for model/animation/bone counts.
