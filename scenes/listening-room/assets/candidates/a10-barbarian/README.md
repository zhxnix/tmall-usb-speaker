# A10 · 旅途蛮族

Source: [KayKit Character Pack: Adventurers](https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0), `Characters/gltf/Barbarian.glb`.

License: CC0 1.0; the pack license is kept in `LICENSE.txt`. This is a local customer candidate and does not replace the original customer. `main.glb` keeps the barbarian clothing, cape and hat, source skin weights and animations. Axes, shield and mug were removed so the shop controller can supply the record and phone props.

The source rig has the same 41-bone KayKit humanoid layout as A10 兜帽盗贼: `upperarm.l/r`, `lowerarm.l/r`, `wrist.l/r`, `hand.l/r` and `handslot.l/r`. `Idle` and `Walking_C` are retained, together with the pack's other animation clips. Recommended fitting is shoulder height 1.10 m and head scale 0.58.
