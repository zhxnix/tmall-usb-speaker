# A10 · 无兜帽盗贼

Source: [KayKit Character Pack: Adventurers](https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0), `Characters/gltf/Rogue.glb`.

License: CC0 1.0; the pack license is kept in `LICENSE.txt`. This is a local customer candidate and is separate from the existing hooded rogue. `main.glb` keeps the unhooded rogue clothing, cape and face, source skin weights and animations. Knife, crossbow and throwable props were removed so the shop controller can supply the record and phone props.

The source rig has the same 41-bone KayKit humanoid layout as the hooded rogue: `upperarm.l/r`, `lowerarm.l/r`, `wrist.l/r`, `hand.l/r` and `handslot.l/r`. `Idle` and `Walking_C` are retained, together with the pack's other animation clips. Recommended fitting is shoulder height 1.10 m and head scale 0.58.
