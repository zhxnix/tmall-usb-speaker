# A11 · Quaternius Captain Barbarossa

Original pack and licence evidence: https://quaternius.com/packs/piratekit.html (CC0).
Author's public download folder: https://drive.google.com/drive/folders/1KjMzhVsDcyvYMWeVjZcRfuu8auBLpNi2
Source file: `Characters_Captain_Barbarossa.gltf`, downloaded directly from the author's glTF folder (Drive file `1jL12GSoJAJah5CkZWbPM6BBdM4R--hU1`). All textures and buffers are already embedded in the source.

`main.glb` preserves the original skin weights and all 14 source animation tracks without skeleton re-export. The cutlass (`Weapon_Cutlass`) and shoulder parrot (`Ernest`) attachments are detached for a clear, unarmed shop visitor; the captain's hat, beard and costume are retained. A source tool is at `tools/prepare_quaternius_candidates.py`. See `model-info.json` for model/animation/bone counts.
